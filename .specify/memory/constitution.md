# A 股中低频量化交易系统 · Constitution（项目章程）

**项目**: research-finai · 个人 A 股中低频量化交易系统（v1）
**性质**: 本章程是整个项目不可协商的最高纪律。spec、plan、tasks 与一切实现均须对照本章程检查；任何冲突以本章程为准。
**依据**: 第 1-4 轮调研交付体系（00-16 号文档，V5）沉淀的纪律 + 用户既定约束与口头指令（2026-08-29 确认）。
**适配说明**: 按 spec-kit v1.0.1 lean preset 的 constitution 骨架手工适配；每条原则标注了证据锚点（文档编号），便于复核与修订。

## 核心原则

### I. 零前视（Point-in-Time，NON-NEGOTIABLE）

回测与研究中只能使用"信号时点已公开可得"的信息。

- 财务/公告类数据一律按**公告日（pubDate）**对齐，不按报告期；baostock 季频财报含 pubDate 已于第四轮实测确认（12 号 §9-A），降级方案保守性验证成立率 100%（中位滞后 3 天/最大 46 天）。
- **前复权价是时间轴上的未来函数**（08 号 D1）：历史信号特征禁止直接用"当前基准"前复权价；用后复权价或以信号时点为基准的重构复权价。
- 指数成分、股票池构建必须回放历史时点成分，禁止幸存者偏差（08 号 D4）。
- 任何新数据源接入前，先回答"它在历史上哪一天可得"，答案写入数据字典后方可接入。

### II. 数据卫生（NON-NEGOTIABLE）

脏数据宁可响亮失败，不可静默容忍。

- **停牌脏行强制过滤**：baostock 停牌日返回"前值填充"脏行（OHLC=前收、volume=0、不报错），入库前必须 `df[df.tradestatus=="1"]`（12 号 §9-A 实测，100% 命中）。
- **复权因子不跨源混用**：跨源分歧唯一来源为 2005-2006 股改对价（新浪计入、baostock 不计入，×1.32~1.35）；2015 年后两源收益差 <0.2pp。跨源对账前先对齐行数与日期。
- 复权价存储优先 baostock hfq（10 位小数，新浪仅 2 位）。
- 一切采集数据进入"采集 → 清洗 → 校验 → 入库"管道；校验失败即中断并告警，禁止自动填充或跳过。

### III. 成本真实性

回测不计全成本的策略结果一律视为无效。

- 必须计入：佣金（**最低 5 元/边**）、印花税（卖出 万5，2023-08-28 起；此前 千1）、过户费（万0.1 双边）、经手费（沪深 0.00341% 双边；**北交所 0.125‰ 双边，约为沪深 3.67 倍**，不可混用，07 号）、真实滑点。
- 滑点禁止用 0 或固定小比例（08 号 C1）；中小盘进出须考虑冲击成本（08 号 C2）。
- 组合构建层面：10-15 万资金下，**单票建仓低于 2 万元不开仓**——最低 5 元佣金会抹平低佣优势（第四轮成本实算）；15 只以上月频年拖累破 2%。

### IV. 执行语义真实（NON-NEGOTIABLE）

回测撮合必须反映 A 股真实交易约束；任何一挂，该框架的回测结果不得被信任（13 号）。

- **T+1**：当日买入不可当日卖出；卖出资金次一交易日可用于买入、不可取出。
- **涨跌停/一字板**：禁止强制撮合（08 号 D3）；涨停买入、跌停卖出默认不成交。
- **停牌期**：不可下单、不可成交；停牌估值按既定规则处理并在回测与模拟盘保持一致。
- **收盘价信号不可当日成交**（08 号 E1）：默认成交模型为次一交易日开盘价（可在 plan 中论证变更，但必须显式声明并做敏感性对比）。
- **13 号 5 个必挂用例**（涨停买入/跌停卖出/停牌日下单/除权日持仓/T+1 当日买卖）全部通过前，回测引擎不得用于任何策略结论。

### V. Long-only v1 · 多市场留口

- v1 = **纯多头、无杠杆、无做空**。这不是偏好，是约束的现实（两融/股指期货/ETF 期权三道 50 万门槛均不可达；转融券 2024-07-11 起暂停；11 号与第五轮调研）。
- 风控只能靠**仓位管理 + 止损/退出规则**，不依赖对冲；仓位管理器（择时空仓/减仓）是一等公民。
- 为美股/韩股扩展预留六处接口：持仓用**带符号数量**、组合目标用**可为负的权重**、订单语义为**开仓/平仓+方向**、费用模型**按市场可插拔**、交易日历/时区/结算周期**可配置**、涨跌停**可配置**（美股无涨跌停有熔断、韩股 ±30%）。
- **留口 ≠ 实现**：空头分支写 `NotImplementedError` + TODO，禁止现在就写完整多空引擎（YAGNI，见原则十）。

### VI. 免费与合规

- 数据源限于**免费渠道**（baostock 为主、新浪/腾讯校验互补；东财系本机不可达已证实，换机需复测）；**禁止付费购买数据、禁止注册新账号**。
- 采集限速四件套：**串行 + 间隔 ≥0.5s + 指数退避重试 + 熔断**；写入幂等（按日期分区覆盖或唯一约束），禁止重试风暴（08 号 R3）。
- **先报告后交易**（11 号）：实盘前完成程序化交易报告（报告表官方 xlsx 已取得，上证发〔2023〕144 号页）；信息变更报备时限 = 下一个自然月第五个交易日前。
- 不触碰高频认定线（11 号高频距离测算）；申报速率与单日笔数在报告中如实填写。
- 账户、密码、密钥一律走环境变量/本地密钥文件，禁止硬编码进代码或文档。

### VII. 模拟盘闸门（NON-NEGOTIABLE）

- 回测验收通过后，**模拟盘 ≥ 6 个月**（用户既定纪律，严于 03 号 Phase 4 的"4 周起"，以严者为准）；模拟盘与实盘同等严肃（03 号 §2）。
- 模拟盘与回测指标偏差超出容忍带（容忍带在 plan 中量化）时，回到策略/执行模型排查，不得直接上实盘。
- 实盘必须从**最小可验证资金**开始（03 号 Phase 5），且每次升级（模拟盘 → 小额实盘 → 加仓）都须**用户书面确认**。

### VIII. 调研先行 · 阶段门禁

- 按 03 号 Phase 0-6 顺序推进；每个 Phase 的验收标准通过后才能进入下一个。
- **文档级证据 ≠ 行为级证据**：第四轮已两次证明案头结论会被实测推翻（baostock 分钟线起始年份、公告日字段）；框架/数据/撮合的任何关键断言，能实测的一律实测。
- **开工建系统的决定不由 AI 单方面做出**：到达"可以开始建系统"的判断点时，必须停下，向用户陈述理由并征得同意（用户指令，2026-08-29）。本章程本身的存在不构成开工授权。
- 遇到决策点：给出 ≥2 个方案，比较成本/收益/风险，选出最佳并说明理由，然后执行（用户授权，2026-08-29）；涉及资金与合规的决策除外——那类必须用户拍板。

### IX. 证据与修订纪律

- 关键结论 **≥2 独立可追溯来源**；时效性数字一律标注检索/实测日期。
- 来源冲突时并列呈现，不强行改判；单源结论标注 `[单源待证]`。
- 修改既有文档必须在其文末**修订日志**登记（改了什么/为什么/依据来源）；台账回填在 14 号 §七 留痕。
- 易变数据按 14 号台账 SOP 复查（月度 2026-09-28 到期、季度 2026-11-28 到期）。

### X. 简洁与单人可运维

- **YAGNI**：单人项目，优先简单；拒绝重型 MLOps/中间件/微服务，除非成本收益论证成立。
- **宁可响亮失败，不可静默继续**：无人值守任务出错时优先告警停止，而不是带伤运行。
- 一切定时任务必须**可重跑、幂等、留痕**；自动修复动作保留人工确认痕迹。
- 系统必须在单台 Windows 机器、单人维护的条件下可持续运转；任何"需要另一个人/另一台机器才能运维"的设计默认拒绝。

## 附加约束（本章程生效期间的事实参数）

- 初始资金：**10-15 万人民币**（成本测算取中位 12.5 万）。
- 持仓：**3-8 只（默认 5），硬上限 10**，单票建仓下限 2 万元。
- 信号频率：**纯日线**；回测起点 **2015-01-01**（覆盖 2015 股灾与 2018 熊市；分钟线仅 2020 年起约 6.5 年，不做小时级）。
- 杠杆：**无**；两融为可插拔扩展点，触发条件"资金 ≥50 万且策略实盘满 1 年"。
- 环境：Windows 单机、Python 3.11、免费数据源、任务计划程序调度。
- 长期规划：先 A 股积累经验，之后美股、韩股（架构留口见原则五）。

## 治理

- 本章程高于一切后续产出（spec/plan/tasks/代码）；冲突时以本章程为准。
- 修订流程：提出修订（含理由与影响范围）→ **用户批准** → 登记修订日志（本文件末尾）→ 同步更新受影响的 spec/plan。AI 不得自行修订章程条款。
- 每次 plan/tasks 评审必须包含一步"章程符合性检查"。
