三、Phase 0-1 环境准备清单（任务三 → 12 号附录 A）

Python / venv

本机 3.13.12 打包版无 venv 模块；建环境用 py -3.11 -m venv（3.11.5）。akshare 1.18.94 装包/import 实测通过。

pip 装包

PyPI 境内直连可达，装包无需代理；清华镜像同步一致备用。

代理陷阱

Clash 类系统代理注册表级常开，Python 默认走 127.0.0.1:7897；NO_PROXY='*' 对 requests 无效——须列域名或 trust_env=False。

接口冒烟

日线（东财）✅ / 5min（新浪）✅ / 交易日历 ✅；min_em 分钟线失败系本机代理层，非上游死亡。
